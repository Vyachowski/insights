## REMOVED Requirements

### Requirement: Expenses by Category widget

**Reason**: The main page is being reworked into a summary («Сводка») of three widgets (Итог, Тренды, Города). The expenses-by-category breakdown does not fit the summary's "grow or shrink / trend or one-off / which cities lead" purpose and belongs with the detailed finance views.

**Migration**: Expense-by-category detail is available on the Data page's expenses tab (filterable by month and category). It is planned to return under the future dedicated «Финансы» tab; it is not part of the «Сводка» page.
