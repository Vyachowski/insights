## ADDED Requirements

### Requirement: Ручное добавление дохода

Система SHALL позволять администратору вручную добавлять запись дохода через UI вкладки «Доходы», без импорта CSV. Кнопка называется «Добавить». Форма собирает дату, сайт (или «Общий (компания)») и сумму в рублях. Запись сохраняется в таблицу `revenues` с суммой, конвертированной в целые копейки, и остаётся после перезагрузки страницы.

#### Scenario: Успешное добавление нового дохода

- **WHEN** администратор нажимает «Добавить», указывает дату и сумму > 0 и подтверждает
- **THEN** система создаёт запись в `revenues` с `date` из формы, `siteId` из выбора (или `null` для «Общий») и `amount` в копейках
- **AND** список доходов обновляется и показывает новую запись, которая сохраняется после перезагрузки

#### Scenario: Сайт не выбран — общий доход

- **WHEN** администратор оставляет выбор сайта пустым («Общий (компания)»)
- **THEN** запись сохраняется с `siteId = null`

### Requirement: Идемпотентность по дате и сайту

Система SHALL трактовать повторное добавление дохода за ту же дату и сайт как обновление суммы, а не как ошибку — так же, как импорт ведёт себя идемпотентно по `(date, siteId)`. Двух записей с одинаковыми `(date, siteId)` не создаётся, что соответствует уникальному индексу таблицы `revenues`.

#### Scenario: Повтор за ту же дату — сумма перезаписывается

- **WHEN** для даты и сайта уже есть запись и администратор добавляет доход за ту же дату и сайт с другой суммой
- **THEN** система обновляет `amount` существующей записи и не создаёт новую строку

#### Scenario: Повтор с той же суммой — без изменений

- **WHEN** добавляется доход за дату и сайт, где уже есть запись с той же суммой
- **THEN** данные не меняются (операция безопасна при повторе)

### Requirement: Только администратор

Система SHALL разрешать ручное добавление дохода только пользователю с правами администратора, как и импорт CSV. Обычный пользователь не видит кнопку «Добавить» на вкладке доходов и не может выполнить действие на сервере.

#### Scenario: Обычный пользователь не видит кнопку

- **WHEN** страницу доходов открывает не-администратор
- **THEN** кнопка «Добавить» на вкладке доходов не отображается

#### Scenario: Серверная проверка прав

- **WHEN** запрос на добавление дохода приходит от не-администратора
- **THEN** сервер отклоняет запрос (проверка `requireAdmin`)
